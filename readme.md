## 🛠️ Step-by-Step Installation Guide (For Beginners)

If you are new to programming or running AI applications locally, follow these simple steps:

### 1️⃣ Install Python and Git
Before running JARVIS, your computer needs Python (to run the code) and Git (to download the code).
* **Python**: Download and install [Python 3.11 or 3.12](https://www.python.org/downloads/). 
  > [!IMPORTANT]
  > During the Python installation, make sure to check the box that says **"Add Python to PATH"** before clicking Install.
* **Git**: Download and install [Git for Windows](https://git-scm.com/download/win) using default options.

### 2️⃣ Download the Code
* Open your **Command Prompt** or **PowerShell** by searching for "cmd" or "powershell" in your Start Menu.
* Clone the repository to your computer:
  ```bash
  git clone https://github.com/KnightFuryXY/J.A.R.V.I.S.git
  cd J.A.R.V.I.S
  ```
  *(Alternatively, click the green **Code** button at the top of this GitHub page, select **Download ZIP**, extract the folder, and open your terminal inside it).*

### 3️⃣ Get a Free Gemini API Key
* Go to [Google AI Studio](https://aistudio.google.com/apikey).
* Log in with a Google account.
* Click **Create API Key** and copy it.

### 4️⃣ Set Up the Environment
* In your command prompt, run the setup script to automatically install requirements:
  ```bash
  python setup.py
  ```

### 5️⃣ Boot J.A.R.V.I.S.
* Launch the assistant:
  ```bash
  python main.py
  ```
* On first launch, a setup panel will appear. Paste your API key and click **Initialise Systems**.

### 6️⃣ How to Control
* **Voice Mode**: Speak naturally to talk to JARVIS.
* **Keyboard Mode**: Type commands in the entry bar at the bottom and click **Send**.
* **Mute Control**: Toggle your microphone off or on by pressing **`F4`** or clicking the **LIVE** button on the bottom left.
